# Kairos 初版の確定範囲

## 目的

低コストかつ最短で、個人または小規模グループが予定とタスクを安全に管理できる iOS / Android アプリを公開する。

## 初版に入れる機能

1. Email/Password によるアカウント作成、ログイン、ログアウト、パスワード再設定
2. 個人の予定の作成、編集、削除
3. 個人のタスクの作成、完了、削除
4. 小規模グループの作成とメンバー管理、予定共有
5. 端末内ローカル通知による予定・タスクリマインダー
6. アカウントと本人のデータの削除
7. アプリ内から開けるプライバシーポリシーとサポートページ

## 初版から除外する機能

- Google、Apple、電話番号、匿名ログイン
- 位置情報、地図、常時バックグラウンド処理
- 画像・動画・ファイルのアップロード
- サーバープッシュ通知
- Cloud Functions の本番デプロイ
- アプリ内課金、有料プラン、広告、AI 機能
- 外部カレンダー連携、データエクスポート

## 無料運用の制約

Firebase は Spark プランのまま利用し、請求先アカウントを追加しない。Firestore を直接利用し、Cloud Functions と Storage を本番公開しない。Firebase Hosting はプライバシーポリシーとサポートページの公開だけに使う。

ストア申請には Apple Developer Program の年額 99 USD と Google Play Developer の登録時 25 USD が必要である。
