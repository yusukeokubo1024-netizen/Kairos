# Kairos - UI/UXデザインガイドライン

## 🎯 デザイン哲学

**スローガン**: 「シンプルで見やすく、直感的に操作できる」

### 設計原則
1. **ミニマリズム** - 不要な要素を排除
2. **階層性** - 重要度順に情報を整理
3. **一貫性** - 統一されたデザインシステム
4. **アクセシビリティ** - すべてのユーザーが使いやすい
5. **レスポンシブ** - あらゆるデバイスに対応

## 📐 デザインシステム

### 1. カラーパレット（ライトモード）

#### プライマリカラー
```
Primary Blue:      #2563EB (安心感・信頼感)
Secondary Blue:    #0EA5E9 (アクティビティ)

Neutral Gray:      #6B7280 (ニュートラル)

#### 背景色
```

#### テキストカラー
```

#### 見出し
```

```

```

## 🎬 主要フロー

### 1. ホーム → スケジュール詳細

```
[カレンダー表示]
    ↓ (タップ)
[スケジュール詳細モーダル]
├─ タイトル
├─ 日時 / 位置情報
├─ 参加者
├─ 説明
└─ [編集] [削除] [共有]
```

### 2. 新規作成フロー

```
[+ 新規] ボタン
    ↓
┌──選択──────┐
│ スケジュール │  ← 予定を作成
│ タスク      │  ← TODOを作成
│ グループ    │  ← グループを作成
└─────────────┘
```

### 3. 検索フロー

```
[🔍 検索ボックス]
    ↓ (入力)
[リアルタイム検索結果]
├─ スケジュール
├─ タスク
└─ グループ
```

## ✨ インタラクション設計

### アニメーション（フレームワーク: Cupertino）

| 動き | 時間 | 用途 |
|------|------|------|
| フェードイン | 200ms | 画面遷移 |
| スライドアップ | 300ms | モーダル表示 |
| スケール | 150ms | ボタンタップ |
| バウンス | 400ms | 通知表示 |

### ホバー・タップ状態

```
通常状態:       背景 = 白, 影なし
ホバー:        背景 = #F9FAFB, 影なし
タップ:        背景 = #E5E7EB, スケール 98%
長押し:        メニュー表示
```

## 📐 レスポンシブ設計

### ブレークポイント

```
小 (xs):  < 360px   (小型スマートフォン)
中 (sm):  360-480px (標準スマートフォン)
大 (md):  480-768px (大型スマートフォン/タブレット小)
超大 (lg): > 768px  (タブレット/iPad)
```

### 対応内容

```
xs: 1カラム表示、フォント削減
sm: 1カラム表示、標準表示
md: 2カラム表示可能
lg: サイドバー追加
```

## 🎯 FlutterFlowでの実装ポイント

### 推奨コンポーネント
- **カレンダー**: `table_calendar` パッケージ
- **アイコン**: Material Icons / Ionicons
- **カード**: `Card` ウィジェット
- **検索**: `TextField` + フィルタロジック
- **ナビゲーション**: `BottomNavigationBar`

### スタイルガイド
- パディング: `EdgeInsets.symmetric(horizontal: 16, vertical: 12)`
- ボーダーラディウス: `BorderRadius.circular(8)`
- シャドウ: `elevation: 2` (カード)
